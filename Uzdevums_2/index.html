programmēšana

Programmēšana ir proces, kurā tiek izstrādātas datorprogrammas vai mājas lapas.

Majas lapu izveidē tiek izmantotas šādas valodas:

  1. HTML
  2. CSS
  3. JavaScript

HTML

HTML (HyperText Markup Language) ir valoda, kas tiek izmantota, lai izveidotu mājas lapas struktūru un saturu.

CSS

CSS (Cascading Style Sheets) ir valoda, kas tiek izmantota, lai stilizētu mājas lapas izskatu un dizainu.

JavaScript

JavaScript ir programmēšanas valoda, kas tiek izmantota, lai pievienotu interaktivitāti un dinamiku mājas lapām.
